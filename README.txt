KIM ADDONS PREMIUM UI
======================
واجهة Static جاهزة لـ GitHub Pages.

الملفات:
- index.html
- style.css
- app.js
- hero-reference.png

النشر:
1) أنشئ Repository على GitHub.
2) ارفع الملفات إلى الفرع الرئيسي.
3) Settings > Pages > Deploy from branch.
4) اختر main / root.
5) انتظر رابط GitHub Pages.

هذه نسخة واجهة فقط. الحسابات والتعليقات والتقييمات والتحميلات حالياً محاكاة واجهة، ويمكن ربطها لاحقاً بـ Supabase.
